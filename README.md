# Real-Time Student Attention & Engagement Detection

## Overview

A computer vision and machine learning system that
estimates visible student engagement-related behavior
from webcam video.

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas
- Scikit-learn
- Random Forest
- Streamlit

## Architecture

Webcam
↓
Face Detection
↓
Facial Landmarks
↓
Feature Engineering
↓
Machine Learning
↓
Temporal Analysis
↓
Real-Time Dashboard

## Features

- Face detection
- Facial landmark detection
- Eye state estimation
- Head orientation analysis
- Behavioral classification
- Temporal smoothing
- Real-time dashboard

## ML Model

Random Forest Classifier

## Important Limitation

The system estimates visible behavior from camera
signals. It does not directly measure a student's
internal mental state or attention.
